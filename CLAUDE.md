# Правила роботи в проєкті Band Hero

## Розподіл роботи між моделями
- Головна модель **не пише весь код сама**. Її роль — ставити задачі субагентам і **перевіряти їхній код** (читати diff, запускати тести, checker).
- **Легкі задачі** (пошук, дрібні правки, перейменування, прості фікси) — субагент на **haiku**.
- **Решта задач** (нові фічі, логіка гри, мультиплеєр, рефакторинг) — субагент на **sonnet**.
- Після роботи субагента — перевірка: `npm test` + агент `checker` перед тим, як казати «готово».
