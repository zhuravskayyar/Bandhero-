# План покращень Band Hero (за плейтестом)

Джерело: `docs/playtest-report.md`. Виконання — субагенти по черзі (усі правки в `game.html`), після кожного етапу `npm test` + рев'ю diff.

## Етап 1 — швидкі виправлення
- [x] 1a (haiku): HP у HUD без дробів (B3); категорія «Гітарний технік»/помічників не «Шкода» (B4); зрозумілий підзаголовок екрана вибору; підпис пісні замість «?».
- [x] 1b (sonnet): кооп-пауза гостя (B1) — гість може зняти свою паузу, хост бачить хто поставив; повернення гостя після F5 через `sessionStorage` (B2); зрозуміле повідомлення «busy»; підтвердження «Повернути гурт у лобі».
- [x] 1c (sonnet): меню — вибір інструмента вище жанрів, регулятор гучності не перекриває картки.
